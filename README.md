# ⚽ Estoril Praia — Bootstrap Redesign

> Same club, better code. A Bootstrap 5 rebuild of the original Estoril Praia website.

A complete redesign of the previous pure-CSS Estoril Praia site, this time using Bootstrap 5. Same theme, completely different approach to layout and components.

## 📦 What's Inside

- 🔲 Bootstrap 5 Grid system and utility classes
- 🧭 Responsive navbar with brand logo
- 🖼️ Image gallery with consistent `aspect-ratio` cropping
- 📬 Contact section with form and embedded Google Maps
- ⬆️ Fixed "back to top" button
- 🔤 Google Fonts (`Orbitron`) combined with Bootstrap
- 🎨 Custom CSS layer for club branding (yellow `#FFEE00` + blue)
- 🦶 Sticky footer with `min-height: 100vh` pattern
- 🔣 Bootstrap Icons and FontAwesome

| Feature | v1 (Pure CSS) | v2 (Bootstrap) |
|---|---|---|
| Layout | Manual Flexbox | Bootstrap Grid |
| Navbar | Built from scratch | `navbar` component |
| Responsiveness | Partial | Built-in |
| Forms | None | Bootstrap form controls |
| Icons | SVG via CDN | Bootstrap Icons / FontAwesome |
